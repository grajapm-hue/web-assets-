# Thayam 5×5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the 5×5 Thayam board as a new, fully playable puzzle mode in `mathmatrix/beta.html`, matching the approved spec exactly, shipped to beta for Raja's own validation before the 7×7 board (a separate follow-up plan) is started.

**Architecture:** One new self-contained IIFE (matching Pallanguzhi 4-player's own structure), added to `beta.html`. The board's two ring levels (outer, inner) are generated by one geometric walking function rather than hand-typed cell arrays, so the routing model is provably correct instead of guessed. Every other subsystem (turn-passing, the turn-pointer arrow, player selection, mode-switching, save/resume) is reused directly from Pallanguzhi 4-player and the puzzle-resume feature rather than rebuilt.

**Tech Stack:** Vanilla JS (no framework, matches the whole file), inline CSS, headless-Chrome test scripts under `mathmatrix/tools/` (the pattern already used for every other suite in this app).

**Spec:** `docs/superpowers/specs/2026-08-25-thayam-design.md`

## Global Constraints

- 5×5 board, 3 pieces per player, 4 colours (reuse `SIDES = ['A','B','C','D']` naming, matching Pallanguzhi).
- Dice: two "kattai" dice, each 0–3. Roll totals and their meaning (from the spec, Part 1 "Taking a turn" and Part 2 "Dice + pity system"):
  - Thayam (a 1 total, from 1+0): required to bring a piece out of home; grants a bonus roll.
  - 2, 3, 4: ordinary move, no bonus roll.
  - 5 (2+3): bonus roll.
  - 6 (3+3): bonus roll.
  - 12 (0+0, i.e. both dice blank): bonus roll.
- Anti-clockwise direction throughout — both the piece path around the board and turn-passing (`A → D → C → B`), reusing Pallanguzhi 4-player's exact convention (`((from - k) % 4 + 4) % 4`), not a new one.
- Pity system: per-player counters at the three chokepoints (leaving home, entering centre, unlocking the inward pivot via a capture); once a counter crosses a threshold randomised between 5 and 10, the next relevant roll is forced to succeed.
- No Skip button for a forced dead turn — auto-detect and auto-pass (spec, "When there's genuinely nothing to play").
- Every rule from the spec's Part 1 applies; nothing in Part 1 is renegotiable in this plan — only *how* it's built (Part 2) is decided here.
- `beta.html` is 13,000+ lines; every task below states exact line-anchor context so a fresh worker can find the right spot without reading the whole file.

```js
// Throwaway: proves the ring-walk geometry before it goes anywhere near a
// board. No DOM needed -- this is pure arithmetic, checked with plain
// Node assertions.
function ringWalk(N, k) {
  var lo = k, hi = N - 1 - k;
  if (lo > hi) return [];
  if (lo === hi) return [[lo, lo]];
  var midCol = Math.floor((lo + hi) / 2);
  var cells = [];
  for (var c = midCol; c >= lo; c--) cells.push([lo, c]);
  for (var r = lo + 1; r <= hi; r++) cells.push([r, lo]);
  for (var c2 = lo + 1; c2 <= hi; c2++) cells.push([hi, c2]);
  for (var r2 = hi - 1; r2 >= lo; r2--) cells.push([r2, hi]);
  for (var c3 = hi - 1; c3 > midCol; c3--) cells.push([lo, c3]);
  return cells;
}

function assertEq(actual, expected, label) {
  var a = JSON.stringify(actual), e = JSON.stringify(expected);
  if (a !== e) { console.log('FAIL ' + label + '\n  got:      ' + a + '\n  expected: ' + e); process.exitCode = 1; }
  else console.log('PASS ' + label);
}

// 5x5 outer ring (k=0): 16 cells, anti-clockwise from pink's own gate (0,2).
assertEq(ringWalk(5, 0), [[0,2],[0,1],[0,0],[1,0],[2,0],[3,0],[4,0],[4,1],[4,2],[4,3],[4,4],[3,4],[2,4],[1,4],[0,4],[0,3]],
  '5x5 outer ring: 16 cells, correct anti-clockwise order from (0,2)');

// 5x5 inner ring (k=1): the 8 cells immediately surrounding the centre (2,2).
var inner = ringWalk(5, 1);
assertEq(inner.length, 8, '5x5 inner ring has 8 cells');
var innerSet = inner.map(function(p){ return p.join(','); }).sort();
assertEq(innerSet, ['1,1','1,2','1,3','2,1','2,3','3,1','3,2','3,3'], '5x5 inner ring is exactly the 8 cells around (2,2)');

// Every colour's own gate sits at index colourIdx * (ringLength/4) on ring 0 --
// this is what lets colourOffset be a formula instead of a lookup table.
var outer = ringWalk(5, 0);
assertEq(outer[0 * 4], [0,2], "pink's gate (A, offset 0) is the outer ring's own start");
assertEq(outer[1 * 4], [2,0], "green's gate (index 4) is (2,0), the left-mid entry");
assertEq(outer[2 * 4], [4,2], "yellow's gate (index 8) is (4,2), the bottom-mid entry");
assertEq(outer[3 * 4], [2,4], "blue's gate (index 12) is (2,4), the right-mid entry");

// And the SAME formula holds one ring in: the inner ring's own "north" cell,
// which is where a piece pivoting in from the outer ring naturally arrives,
// sits at the same colour-index * (ringLength/4) spacing.
assertEq(inner[0], [1,2], "pink's own axis on the inner ring is (1,2), directly under its gate");
assertEq(inner[1 * 2], [2,1], "green's own axis on the inner ring, offset by ringLength/4 = 2");
```

```js
  (function(){
    /* THAYAM RING GEOMETRY.

       Generates each board size's ring levels from plain geometry instead
       of hand-typed cell arrays -- proven correct once here (see
       tools/_diag-thayam-ring.js during planning) rather than trusted by
       eye. `k` is how many cells in from the board's own edge: k=0 is the
       outermost ring, k=1 is one step in, and so on. Walking direction is
       ANTI-CLOCKWISE starting from each ring's own top-middle-ish cell --
       confirmed against Raja's reference images (top-mid moving LEFT
       first, down the left side, along the bottom, up the right), the
       same direction already fixed for Pallanguzhi 4-player's own ring.

       Every colour's own gate sits at colourIndex * (ringLength / 4) on
       ring 0, and the SAME spacing holds one ring further in -- proven in
       the diagnostic, not assumed -- so a piece's real board cell needs no
       per-colour lookup table, just this one formula. */
    function thayamRing(N, k){
      var lo = k, hi = N - 1 - k;
      if (lo > hi) return [];
      if (lo === hi) return [[lo, lo]];
      var midCol = Math.floor((lo + hi) / 2);
      var cells = [];
      for (var c = midCol; c >= lo; c--) cells.push([lo, c]);
      for (var r = lo + 1; r <= hi; r++) cells.push([r, lo]);
      for (var c2 = lo + 1; c2 <= hi; c2++) cells.push([hi, c2]);
      for (var r2 = hi - 1; r2 >= lo; r2--) cells.push([r2, hi]);
      for (var c3 = hi - 1; c3 > midCol; c3--) cells.push([lo, c3]);
      return cells;
    }
    /* All ring levels for one board size, outermost first, stopping once a
       ring would be empty or collapse to the centre cell itself (which is
       the goal square, handled separately -- never part of a ring). */
    function thayamRings(N){
      var out = [];
      for (var k = 0; k * 2 < N - 1; k++) out.push(thayamRing(N, k));
      return out;
    }
    window.__thayamRing = thayamRing;
    window.__thayamRings = thayamRings;
  })();
```

**A note on IIFE structure for every task below:** each task adds its own **separate, self-closing** IIFE, placed directly after the previous task's — never nested inside another task's IIFE, and never left open across a commit. A worker following one task in isolation must always be able to load `beta.html` in a browser afterward without a syntax error; a shared-but-unclosed IIFE spanning tasks would violate that. Cross-task state is passed only through the `window.__thayam*` functions each task exposes (its own "Produces" list), never through a raw shared closure variable — this is why later tasks call e.g. `window.__thayamRings(5)` or `window.__thayamPieces()` rather than reaching for a bare `rings5` or `thPieces` variable that belongs to a different task's IIFE.

```js
  (function(){
    function thayamRollDice(){
      var d0 = Math.floor(Math.random() * 4), d1 = Math.floor(Math.random() * 4);
      var total = d0 + d1;
      if (d0 === 0 && d1 === 0) total = 12;   // both blank is a 12, not a 0
      var isThayam = total === 1;
      var bonusRoll = total === 1 || total === 5 || total === 6 || total === 12;
      return { d0: d0, d1: d1, total: total, isThayam: isThayam, bonusRoll: bonusRoll };
    }
    window.__thayamRollDice = thayamRollDice;

    /* PITY SYSTEM -- one counter per (chokepoint, player). Raja: "every 5 to
       10 twist down will get sure thayam." A random threshold per player
       per chokepoint (picked fresh each time the counter resets) means the
       exact moment it fires is not predictable from watching a few rounds,
       while still guaranteeing it lands inside the promised window. */
    var pityCounters = {};   // key: kind+'|'+playerId -> { misses, threshold }
    function pityKey(kind, playerId){ return kind + '|' + playerId; }
    function thayamPityReset(kind, playerId){
      pityCounters[pityKey(kind, playerId)] = { misses: 0, threshold: 5 + Math.floor(Math.random() * 6) };   // 5..10 inclusive
    }
    function thayamPityCheck(kind, playerId){
      var c = pityCounters[pityKey(kind, playerId)];
      if (!c) { thayamPityReset(kind, playerId); c = pityCounters[pityKey(kind, playerId)]; }
      return c.misses + 1 >= c.threshold;   // this roll, if it's also a natural miss, would be forced instead
    }
    function thayamPityRecord(kind, playerId, hit){
      if (hit){ thayamPityReset(kind, playerId); return; }   // a natural hit resets the counter, same as a forced one
      var c = pityCounters[pityKey(kind, playerId)];
      if (!c) { thayamPityReset(kind, playerId); c = pityCounters[pityKey(kind, playerId)]; }
      c.misses++;
    }
    window.__thayamPityReset = thayamPityReset;
    window.__thayamPityCheck = thayamPityCheck;
    window.__thayamPityRecord = thayamPityRecord;
  })();
```

Add as its own new, self-closing IIFE, placed directly after Task 3's dice/pity IIFE. It needs the ring lengths and gate positions from Task 1's public `window.__thayamRings(5)` — recomputing that locally is cheap (24 cells) and keeps this module from reaching into another task's closure, matching the IIFE-structure note above:

```js
  (function(){
    var SIDES_T = ['A', 'B', 'C', 'D'];
    var rings5 = window.__thayamRings(5);
    function ringLen(lap){ return rings5[lap].length; }
    var CENTER_T = 2 * 5 + 2;
    var realCell = window.__thayamRealCell;
    var SAFE_T = window.__thayamState().safe;

    var thPieces = [];   // { side:'A', idx:0, lap:'home'|'outer'|'inner'|'finished', position:0, lastCell:null }
    var thHasCut = {};   // side -> bool, per-game
    var PIECES_PER_SIDE = 3;

    function thayamNewGame(enabledSides){
      thPieces = [];
      thHasCut = {};
      SIDES_T.forEach(function(s){ thHasCut[s] = false; });
      enabledSides.forEach(function(s){
        for (var i = 0; i < PIECES_PER_SIDE; i++){
          thPieces.push({ side: s, idx: i, lap: 'home', position: 0, lastCell: null });
        }
      });
    }
    window.__thayamNewGame = thayamNewGame;
    window.__thayamPieces = function(){ return thPieces; };

    function sideIdxOf(side){ return SIDES_T.indexOf(side); }

    /* Moving a piece forward by `steps` along its OWN lap. Refuses to cross
       into the next lap (cut-mandate) unless hasCut is true for that side --
       the piece simply stops at the current lap's last position instead,
       exactly matching Raja's own description: "forced to pause there's
       last standing box." That word "pause" matters: a piece already
       sitting AT that last position, still without a capture, has to
       genuinely refuse every further roll (return false) so the player
       must spend that roll on a different piece -- not silently
       "succeed" by landing on the exact same cell it already occupies,
       which would look like a legal move but move nothing. Refuses to
       enter the centre on anything but an exact landing. */
    function advancePiece(piece, steps){
      var side = piece.side, colourIdx = sideIdxOf(side);
      if (piece.lap === 'home'){
        piece.lap = 'outer'; piece.position = 0;   // the Thayam that brought it out always lands it on its own gate
        piece.lastCell = realCell(0, colourIdx, 0);
        return true;
      }
      var lapIdx = piece.lap === 'outer' ? 0 : 1;
      var len = ringLen(lapIdx);
      if (lapIdx === 0 && piece.position === len - 1 && !thHasCut[side]) return false;   // already at the last standing box -- genuinely stuck, not a no-op success
      var newPos = piece.position + steps;
      if (lapIdx === 1 && newPos === len){   // exact landing on the final inner-ring step means the centre, not a wraparound
        piece.lap = 'finished'; piece.position = 0; piece.lastCell = CENTER_T;
        return true;
      }
      if (lapIdx === 1 && newPos > len) return false;   // overshoot -- centre needs an exact count, this roll can't be used here
      if (newPos >= len){
        if (lapIdx === 0 && !thHasCut[side]){
          // capped at the boundary -- stays on the outer ring, does not pivot
          piece.position = len - 1;
          piece.lastCell = realCell(0, colourIdx, piece.position);
          return true;
        }
        if (lapIdx === 0){   // hasCut is true -- pivot to the inner ring, carrying the excess steps forward
          piece.lap = 'inner';
          piece.position = newPos - len;
          piece.lastCell = realCell(1, colourIdx, piece.position);
          return true;
        }
      }
      piece.position = newPos;
      piece.lastCell = realCell(lapIdx, colourIdx, piece.position);
      return true;
    }

    /* Capture: scan every OTHER side's pieces for anyone sitting on the same
       real cell this piece just landed on, off a Mount. No occupancy map --
       just the pieces list, which is at most a handful long. */
    function captureAt(mover, cell){
      if (SAFE_T[cell]) return [];   // Mount squares protect everyone standing there
      var caught = [];
      thPieces.forEach(function(p){
        if (p === mover || p.side === mover.side) return;
        if ((p.lap === 'outer' || p.lap === 'inner') && p.lastCell === cell){
          p.lap = 'home'; p.position = 0; p.lastCell = null;
          caught.push({ side: p.side, idx: p.idx });
        }
      });
      if (caught.length) thHasCut[mover.side] = true;
      return caught;
    }

    function thayamApplyRoll(sideIdx, pieceIdx, rollValue){
      var side = SIDES_T[sideIdx];
      var piece = thPieces.find(function(p){ return p.side === side && p.idx === pieceIdx; });
      if (!piece) return { moved: false, captured: [], won: false };
      if (piece.lap === 'finished') return { moved: false, captured: [], won: false };
      if (piece.lap === 'home'){
        if (rollValue !== 1) return { moved: false, captured: [], won: false };   // only a Thayam brings a piece out
        advancePiece(piece, 0);
        var caughtOnEntry = captureAt(piece, piece.lastCell);
        return { moved: true, captured: caughtOnEntry, won: false };
      }
      var lapBefore = piece.lap;
      var ok2 = advancePiece(piece, rollValue);
      if (!ok2) return { moved: false, captured: [], won: false };
      if (piece.lap === 'finished') return { moved: true, captured: [], won: true };
      var caught = captureAt(piece, piece.lastCell);
      return { moved: true, captured: caught, won: false };
    }
    window.__thayamApplyRoll = thayamApplyRoll;

    /* "Does this player have ANY legal move for this roll" -- the exact
       check Task 5's auto-pass needs, kept here because it has to use the
       same advancePiece/lap rules the real move uses, not a re-derived
       approximation of them. Runs the move on a CLONE, never the real
       piece, so checking never has a side effect. */
    function legalMoveExists(sideIdx, rollValue){
      var side = SIDES_T[sideIdx];
      return thPieces.some(function(p){
        if (p.side !== side || p.lap === 'finished') return false;
        var clone = { side: p.side, idx: p.idx, lap: p.lap, position: p.position, lastCell: p.lastCell };
        if (clone.lap === 'home') return rollValue === 1;
        return advancePiece(clone, rollValue);
      });
    }
    window.__thayamLegalMoveExists = legalMoveExists;

    /* Task 6's tap-to-choose UI needs to check "would THIS SPECIFIC piece
       accept this roll" without applying it -- the same clone-not-mutate
       contract legalMoveExists already relies on, exposed directly rather
       than making Task 6 re-derive advancePiece's own rules. */
    window.__thayamWouldAccept = function(side, pieceIdx, rollValue){
      var piece = thPieces.find(function(p){ return p.side === side && p.idx === pieceIdx; });
      if (!piece || piece.lap === 'finished') return false;
      if (piece.lap === 'home') return rollValue === 1;
      var clone = { side: piece.side, idx: piece.idx, lap: piece.lap, position: piece.position, lastCell: piece.lastCell };
      return advancePiece(clone, rollValue);
    };
  })();
```

```js
      window.__mmSave(thayamKey(), { pieces: pieces, activeSide: window.__thayamActiveSide(), enabled: window.__thayamTurnState().enabled });
    }
    function thayamRestore(){
      var sv = window.__mmLoad(thayamKey(), function(o){
        return Array.isArray(o.pieces) && typeof o.activeSide === 'string' && o.enabled;
      });
      if (!sv) return false;
      window.__thayamSetPieces(sv.pieces);
      window.__thayamSetEnabled(sv.enabled);
      window.__thayamTurnInit(sv.activeSide);
      return true;
    }
    window.__thayamClear = function(){ window.__mmClear(thayamKey()); };

    function renderThayamPieces(){
      document.querySelectorAll('#thayamGrid .thPiece').forEach(function(el){ el.remove(); });
      window.__thayamPieces().forEach(function(p){
        if (p.lap !== 'outer' && p.lap !== 'inner') return;   // home and finished pieces live in the Store panel, not the grid
        var cellEl = document.querySelector('#thayamGrid [data-thayam-cell="' + p.lastCell + '"]');
        if (!cellEl) return;
        var dot = document.createElement('div');
        dot.className = 'thPiece side' + p.side;
        cellEl.appendChild(dot);
      });
    }
    function renderThayamTallies(){
      var pieces = window.__thayamPieces();
      SIDES_T.forEach(function(s){
        var side = pieces.filter(function(p){ return p.side === s; });
        var home = side.filter(function(p){ return p.lap === 'home'; }).length;
        var running = side.filter(function(p){ return p.lap === 'outer' || p.lap === 'inner'; }).length;
        var won = side.filter(function(p){ return p.lap === 'finished'; }).length;
        var el = document.getElementById('thTally' + s);
        if (el) el.innerHTML = '<span>🏠 ' + home + '</span><span>🏃 ' + running + '</span><span>🏆 ' + won + '</span>';
      });
      var look = document.querySelector('#thayamGrid .cell.center .thFace');
      if (look) look.className = 'thFace dir-' + ({ A: 'top', B: 'right', C: 'bottom', D: 'left' })[window.__thayamActiveSide()];
    }
    function flashCapture(cell){
      var cellEl = document.querySelector('#thayamGrid [data-thayam-cell="' + cell + '"]');
      if (!cellEl) return;
      var x = document.createElement('div');
      x.textContent = '✕'; x.style.cssText = 'position:absolute; inset:0; display:flex; align-items:center; justify-content:center; color:#ff3b3b; font-size:20px; font-weight:900; pointer-events:none;';
      cellEl.appendChild(x);
      setTimeout(function(){ x.remove(); }, 500);
    }

    /* One roll -> auto-pass check -> apply to whichever piece the player taps.
       If NO piece can use the roll at all, the turn passes immediately with
       no tap required -- the "no legal move" rule from the spec. */
    var thPendingRoll = null;

    /* Applies the pity system to whatever the dice actually rolled, for
       whichever of the three chokepoints is relevant to THIS player right
       now. A chokepoint's counter is only touched when it's actually
       relevant this turn (Raja's "5 to 10" promise is about rolls that
       could have helped and didn't, not every roll ever made) --
       irrelevant chokepoints are left alone entirely.

       'enter': relevant when the player has a piece still at home.
       'center': relevant when a piece is on the inner ring close enough
         that SOME roll value would land it exactly on the centre.
       'cut': relevant when the player hasn't captured anyone yet and has
         at least one piece parked on the outer ring, unable to pivot in.
         There's no dice VALUE that represents "make a capture happen", so
         this one's forced hit is a direct unlock instead of a re-rolled
         total -- the rule it satisfies is "no longer stuck for lack of a
         capture", not "landed exactly on an opponent". */
    function applyPity(sideLetter, roll){
      var pieces = window.__thayamPieces().filter(function(p){ return p.side === sideLetter; });

      var homePieces = pieces.filter(function(p){ return p.lap === 'home'; });
      if (homePieces.length){
        if (roll.isThayam){
          window.__thayamPityRecord('enter', sideLetter, true);
        } else if (window.__thayamPityCheck('enter', sideLetter)){
          roll.d0 = 1; roll.d1 = 0; roll.total = 1; roll.isThayam = true; roll.bonusRoll = true;
          window.__thayamPityRecord('enter', sideLetter, true);
        } else {
          window.__thayamPityRecord('enter', sideLetter, false);
        }
      }

      var innerPieces = pieces.filter(function(p){ return p.lap === 'inner'; });
      var neededForCentre = innerPieces.map(function(p){ return 8 - p.position; }).filter(function(n){ return n > 0 && n <= 6; });
      if (neededForCentre.length){
        var alreadyExact = neededForCentre.indexOf(roll.total) > -1;
        if (alreadyExact){
          window.__thayamPityRecord('center', sideLetter, true);
        } else if (window.__thayamPityCheck('center', sideLetter)){
          var forcedTotal = neededForCentre[0];
          roll.total = forcedTotal; roll.d0 = Math.min(3, forcedTotal); roll.d1 = forcedTotal - roll.d0;
          roll.isThayam = forcedTotal === 1; roll.bonusRoll = forcedTotal === 1 || forcedTotal === 5 || forcedTotal === 6 || forcedTotal === 12;
          window.__thayamPityRecord('center', sideLetter, true);
        } else {
          window.__thayamPityRecord('center', sideLetter, false);
        }
      }

      var stuckOnOuter = pieces.some(function(p){ return p.lap === 'outer'; }) && !window.__thayamHasCut(sideLetter);
      if (stuckOnOuter){
        if (window.__thayamPityCheck('cut', sideLetter)){
          window.__thayamForceCut(sideLetter);
          window.__thayamPityRecord('cut', sideLetter, true);
        } else {
          window.__thayamPityRecord('cut', sideLetter, false);
        }
      }

      return roll;
    }

    function thayamOnRoll(sideLetter){
      var sideIdx = SIDES_T.indexOf(sideLetter);
      if (window.__thayamActiveSide() !== sideLetter) return;   // not this player's turn
      var roll = thForcedRoll || window.__thayamRollDice();
      thForcedRoll = null;
      roll = applyPity(sideLetter, roll);
      var say = document.getElementById('thaySay');

      if (!window.__thayamLegalMoveExists(sideIdx, roll.total)){
        if (say) say.textContent = sideLetter + ' has no move for ' + roll.total + ' — passing to next player.';
        window.__thayamEndTurn();
        renderThayamTallies();
        return;
      }

      var candidates = window.__thayamPieces()
        .filter(function(p){ return p.side === sideLetter && p.lap !== 'finished'; })
        .filter(function(p){ return window.__thayamWouldAccept(sideLetter, p.idx, roll.total); });

      if (candidates.length === 1){
        thayamCommitRoll(sideIdx, candidates[0].idx, roll);
      } else {
        thPendingRoll = { sideIdx: sideIdx, roll: roll, candidates: candidates.map(function(c){ return c.idx; }) };
        if (say) say.textContent = 'Tap the piece you want to move.';
        document.querySelectorAll('#thayamGrid .thPiece.side' + sideLetter).forEach(function(el){ el.classList.add('active'); });
      }
    }
    function thayamCommitRoll(sideIdx, pieceIdx, roll){
      var result = window.__thayamApplyRoll(sideIdx, pieceIdx, roll.total);
      var say = document.getElementById('thaySay');
      if (result.captured.length && say) {
        var pieces = window.__thayamPieces();
        result.captured.forEach(function(c){
          var p = pieces.find(function(pp){ return pp.side === c.side && pp.idx === c.idx; });
          if (p) flashCapture(p.lastCell);
        });
      }
      renderThayamPieces();
      renderThayamTallies();
      thayamSave();
      var winner = window.__thayamGameOver();
      if (winner){
        if (say) say.textContent = winner + ' wins!';
        window.__thayamClear();
        return;
      }
      if (!roll.bonusRoll) window.__thayamEndTurn();
      renderThayamTallies();
    }
    window.__thayamStartNewGame = function(){
      window.__thayamNewGame(window.__thayamSelectedSides());
      window.__thayamTurnInit(window.__thayamSelectedSides()[0]);
      buildThayam5x5();
      renderThayamPieces();
      renderThayamTallies();
      thayamSave();
    };

    document.querySelectorAll('.rollBtn[data-side]').forEach(function(btn){
      btn.addEventListener('click', function(){ thayamOnRoll(btn.dataset.side); });
    });
    document.getElementById('thayamGrid') && document.getElementById('thayamGrid').addEventListener('click', function(e){
      var pieceEl = e.target.closest('.thPiece');
      if (!pieceEl || !thPendingRoll) return;
      var side = Array.from(pieceEl.classList).find(function(c){ return c.indexOf('side') === 0; }).replace('side', '');
      if (side !== SIDES_T[thPendingRoll.sideIdx]) return;
      var cell = pieceEl.parentElement.dataset.thayamCell;
      var piece = window.__thayamPieces().find(function(p){ return p.side === side && String(p.lastCell) === cell; });
      if (!piece || thPendingRoll.candidates.indexOf(piece.idx) === -1) return;
      thayamCommitRoll(thPendingRoll.sideIdx, piece.idx, thPendingRoll.roll);
      thPendingRoll = null;
      document.querySelectorAll('#thayamGrid .thPiece').forEach(function(el){ el.classList.remove('active'); });
    });

    window.__thayamRestore = thayamRestore;
  })();
```
